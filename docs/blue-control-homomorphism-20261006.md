# 蓝心控制同态：先减少不同作用的控制，再展开状态

新模块 `nohit/engine/control_quotient.py`。`full_local_relation` 新增默认关闭的 `control_quotient=True`，必须同时启用已证明的 `input_latch_quotient`；最终完整出口层仍枚举全部原始mask。未开启生产solver或改动native。

## 同态定义与证明

对一个已知环境块和一个固定持键mask，编码每个物理tick真正读取的控制量：Cancel决定速度；红心读取水平净方向与垂直净方向；蓝心读取当前重力方向的jump位以及垂直于重力的净方向。再加入块后下一tick可能读取的旧jump位。没有已知后继环境时，保留完整mask而不合并。

若两个mask具有相同签名，对任一共同初态，其第一tick的CustomMovement相同（它读取输入前速度）；随后PlayerMovement读取的上述控制量相同，所有非mask输出字段逐bit相同。对第二tick及以后，前tick保存的mask虽然可能不同，但当前方向读取的旧jump位已被签名相等约束。归纳得到整个块每个tick的位置、速度、slam/damage、模式、重力等均相同。碰撞谓词不读取raw mask，因此整条边安全性一致。块末下一tick读取的旧jump也相同，所以对每一个相同后续控制，完整后继状态相同。

这证明该控制分组与已有latch状态商相容。每组保留一个实际mask即保留完整未来可达语言；墙壁、平台、slam或重力切换不破坏此结论，因为我们没有忽略它们，只合并它们对控制的实际读取相同的输入。

固定水平蓝心段，16种箭头组合变为 `jump是否按住 × 垂直净方向{-1,0,1}`，即6组。固定竖直蓝心同理。若块内或后继tick翻转重力，原先未读取的相反方向键可能成为jump，因此签名自动保留两侧jump位，常见为12组。红心的16mask是9种净方向组合。最终若承诺全部full11出口，包括raw mask，本实现不减少该最终层控制。

这是控制语义商，不是按奖励丢弃低分路线。任意依赖未使用按键或按键切换的偏好成本，未必在该商上保持；当前仅作为可达性关系优化。若将来要保留此类精确成本，需要保留别名元数据及必要的成本状态，不能无声使用本商宣称最优评分。

## 完整初态域继续推进至348

随后从上述全部197,616个300入口用分批stream关系继续到500，采用控制商与latch商，不选单个起点。每批4,096个父状态、750k层预算，16.11s内完整达到348的669,344类；352候选超过750k，因此unknown并保存348完整前沿。目标500尚未达到，不能用该报告声称全部500入口已获得。独立目录为 `scratch/complete-blue-300-500-stream/`，包含每层父索引、实际mask、完整初始NPZ及过滤前来源索引；原始完整300、212前沿未覆盖。

`stream_local_relation` 新增默认关闭控制商，以及可选初态NPZ存储，避免大前沿被展开为Python浮点列表。小图差分测试包含分批大小变化、资源停止后resume、完整终态集合一致、初始碰撞过滤后来源索引正确及每条见证重放。该stream测试和控制商套件共15项通过（与上述35项重叠，不相加）。

三段来源链0→212→300→348的16条见证共5,568tick独立重放无碰撞，最终11维逐bit一致，见 `origin-verification.json`。348前沿还有可进一步研究的**已测集合结构**：投影旧mask为下一tick需要的RIGHT jump位后，x扩展状态3,218个、y状态208个，联合对恰好669,344=3,218×208，且原始raw mask可以从jump位与dy净方向恢复。这证明该特定前沿的集合是完整积，尚不证明后续蓝心转移总可独立分轴。尤其任何方向的边界碰撞都会清除slammed；跨下一slam时，不能把该flag错误地当作仅由x轴决定。当前没有开启这种未经证明的优化。

## 不能据此跳过时间控制或直接分解蓝心坐标

固定4tick持键域仍只是声明输入域。若要证明1tick全域，长度h宏边必须表示全部 `U^h` 控制词的关系合成；不能仅凭控制签名省略中途按/松jump。之前20tick入口只是快速取得真实可行路线的受限域，没有替代4tick或1tick完整域。

蓝心也不能无条件拆为独立x/y轴：`heart_solid`判断整颗心是否碰任何Solid，正交方向贴墙能改变本轴CustomMovement与jump/重力支持。具体完整算子反例：场地 `[0,0,100,100]`、水平重力向右、dt=1/240，初态两者同 `x=50,dx=150,dy=150`，仅y分别50和13，mask0；后继x/dx分别 `50.625/152.25` 与 `50/0.75`。因此同x轴状态但不同y能改变x后继，朴素轴同态不成立。

仅在整个生成轨迹的所有相关Solid探针被证明不受另一轴影响的子域，才允许轴分解。对原开场slam贴墙阶段，边界正是关键区域，不可把该限制当作可忽略的小情况。本轮选择控制同态，避免对坐标做未经证明的独立性假设。尚未完成Real HELL全程求解。
