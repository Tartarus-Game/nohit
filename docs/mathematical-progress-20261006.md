# 数学主线的最新结果

本轮按数学优化优先推进。原版 Normal seed42 的历史整局无伤证据保留；
本轮没有新的原版实机整局验收，Real HELL 仍未完成。

## 等价加速，而非削减路线

1. C-space 凸障碍的精确纵截面把逐点 SAT 判断换成有序坐标上的区间运算。
   保留原浮点运算顺序、闭边界、所有联合可达状态和每个微 tick 的安全检查。
   704→708 的全部 79,415,230 个出口逐位一致，耗时从此前缓存核的15.38秒
   降到约3.47秒。新核有明确域检查，域外回原算子。
2. 蓝心先证明两轴计算分解，再用联合位图保留相关性；有 slam 时保留两个
   slammed 位平面；只有在确证可达关系本身为集合积、危险区为可分条带时，
   才直接传播集合积。完整四 tick 开局0→500精确表示81,298,380个full11出口，
   以两个集合积占约5.05MB。详见 complete-blue-opening-500-20261006.md。
3. EOF API 执行序列与 cadence 统一：actions/action_sequence 都是实际执行序列，
   有限求解前缀另存 solver_actions。生产 runner 的独立模拟验证无漏播/重播。

这些优化不证明任意加权奖励的全局最优。权重仍不能改动安全性或删除不等价出口。

## 反向证书改变了调查方向

较广的20tick开局子语言随后完整四tick展开，在1512耗尽；从其全部1492或1400
出口改为每tick所有16输入，仍在1509耗尽。单凭这些结果不能排除其他早期路线。

因此进一步构造保守的反向位置可达性关系。闭网格覆盖所有位置
x∈[254,393], y∈[239,378]，允许每tick任意分量速度≤150，忽略蓝色伤害和
中间碰撞，并用逐浮点运算外扩包络原运动和clamp。整格只有在同一障碍对四个
角的原始碰撞谓词均成立时才删除。这个关系是完整动力学可行路径的超集。

在当前固定240Hz源环境中，V_1264=∅（目标1528）。这项证书覆盖所有符合上述
域的入口，不依赖我们挑选哪条开局，也允许逐tick换键。literal1/240的匹配
窗口同样为空。它证明该声明模型中无法通过此窗口，不能说仅因候选不够多。

进一步独立检查固定60/120Hz：60Hz短窗316→382非空只说明unknown；把窗口
扩到3→8秒后，60Hz在5.25秒反向为空，120Hz也在约5.2667秒为空。因此
“直接改60Hz就能解决”没有证据，当前也没有更改执行协议。

上述结论不是所有时间协议下的原版无解证明。原版runtime是逐RAF推进，固定
240Hz来自我们的compensation/oracle包装器；原版存在每tick的LeaveSpeed+=30，
所以细分时间步不保持同一动力学。详见 fixed-240-wrapper-provenance-20261006.md。

## 下一步与证据边界

不再盲目扩大开局搜索。优先核对证书窗口中模型与原版的伤害框、碰撞多边形、
事件顺序和时间协议。既有原版单次前向差分到1488，未覆盖完整Real HELL，
也没有授权使用原生checkpoint分支搜索。若模型与实际伤害语义一致，必须重新
检验极限自定义谱面必然可无伤的前提，不能为了得到路线修改原版规则。

主要证据：backward-red-certificate-20261006.md、clock-domain-certificates-20261006.md、
cspace-sections-independent-audit-20261006.md。Root独立重跑截面/后向证书相关23项
