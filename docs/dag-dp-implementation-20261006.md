The mathematical reachability recurrence is

`V(E,t,s) = OR_u (safe(E,t,s,u) AND V(E',t+1,F(E,t,s,u)))`.

`E` contains the fixed environment schedule, or the exact bound observation history for player-targeted attacks. `s` is the complete 11-field player state. Every transition checks the original discrete damage predicate at every physics tick. Style weights never enter the safety predicate.

`adaptive_dag.search` evaluates the fixed-environment graph forward, layer by layer. Equal full states and previous controls receive Bellman cost relaxation. It retains only two physical-state frontiers plus compact parent/action arrays. This remains the exhaustive comparison implementation, not an advertised fast route oracle.

The production fixed-environment entry evaluates the same Boolean recurrence on demand using an explicit stack. All untried controls remain available; false states are memoized only after their successors fail or a sound necessary-condition certificate proves failure. Success short-circuits after a complete witness. It has no global priority heap, beam cutoff, coordinate rounding, or scoring-dependent safety margin. This evaluation order does not certify the global minimum style cost.

The parametric environment entry extends that recurrence with exact environment identity. At a `GetHeartPos` boundary, the ordinary movement operator supplies the sampled coordinates, the script resumes with those values, and unsuccessful suffixes return to earlier control alternatives. A bound prefix is never treated as a complete attack.

Input identity reductions are source-specific bisimulations. The previous physical key mask is read only through the jump key used by the next physics tick; all other previous key bits are overwritten by the next control before they can affect future dynamics. Dead-state memoization may therefore ignore those bits, while preserving every physical float bit. Per-control equivalence also checks every tick's active jump key, net movement at normal/slow speed, and the next boundary's jump latch. This reduction belongs to Boolean feasibility. The full-state forward cost reference does not apply it to cumulative switch costs.

The optional gravity-axis failure certificate is an optimistic projection, not a second route generator. In a static blue-heart interval without platforms, it evaluates exact normal-axis movement and jump/release in all four gravity directions at the same four-tick control clock, checking only white rectangles covering the complete tangential interior. Any upcoming arena/mode/teleport/slam/platform change ends the certificate optimistically. Initial tangential wall contact is excluded: for an initially strict interior point, native inclusive solid checks reject every candidate touching a wall, the bounded movement substeps cannot skip the solid band, and late clamping does not move accepted interior points. This invariant excludes tangential influence on the projected dynamics. The memo key retains exact normal position, velocity, jump latch, direction, and horizon. A possible projected continuation cannot establish feasibility; only a proven empty projected set can reject a full state. The same memoized recurrence supplies an optional first viable jump/wait witness for soft ordering. It never replaces full-state safety checks or removes other legal controls.
