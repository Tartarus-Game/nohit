# 静态无攻击终端的释放输入证书

`nohit/engine/terminal_invariant.py` 只提供充分条件，不把 unknown 解释成无解。

## 环境前提

调用方须已证明 Timeline 不再发出命令、没有未来攻击回调或对话回调，骨头、骨刺（包括预警）、激光（包括 ENTER/WAIT/衰减容器）和平台均为空，场地已经固定。`terminal_details` 必须显式提供 `timeline_exhausted=True`、`pending_callbacks=[]`、`pending_dialogue=None`、四个 `active_*` 计数为 0、`arena_settled=True`。当前碰撞栅格为空不满足这些前提。

本证明针对已审计的离散玩家算子，假定无外部游戏状态写入或额外输入。环境的模式、重力方向、最大落速和重摔伤害开关必须与完整玩家状态一致。状态必须在场地内部有效中心范围内；负最大落速及开启重摔伤害暂时返回 unknown。

## 不变集

设输入为全释放 `a=0`。要求玩家速度精确为零，场地 clamp 不改变位置。红心不要求支撑；蓝心额外要求原版 `heart_solid` 在重力方向的 0.2 像素探测为真。因此不是以“看起来着地”或舍入后相等作为证据。

一次原生 tick 的顺序是行为移动、Timeline、玩家输入/重力、场地 clamp。在这些前提下：

1. 旧速度为零，行为位移为零，不产生边界接触伤害。
2. 环境静止且无一次性事件，位置、模式和速度不被 Timeline 改写。
3. 释放输入不产生按下边沿；已有释放边沿只会截断向上的负速度，此处速度为零。
4. 红心输出零速度；蓝心的接触谓词抑制重力，横向输入也为零。
5. 最后 clamp 保持位置。唯一可能变化是 previous input mask 变为零；此后完整运动态固定。

故释放一步后得到 `s*`，对任意合法正 dt（不超过原生 1/30 秒上限）均有 `F_dt(s*,0)=s*`。结合无攻击和无后续事件前提，归纳得到无限无伤尾部。此结论不依赖对有限帧回放“看似稳定”的推断，也不要求停点恰好落在数学地板线上。Slammed 可以仍为 1，因为无后续位移和事件无法触发新的重摔碰撞。

## 有限安全收敛段

`settle_release_to_invariant` 从终端完整状态尝试有限次全释放物理 tick。调用方必须给出后续精确 `dt_sequence`，helper 不猜时间。helper 只复制最后环境行，将一次性 pulse 清零，把 old/mid arena 设为最终 arena，不修改既有 environment schedule。每步直接调用原离散算子并检查伤害，返回每个物理 tick 的输入、dt 和状态；这些动作的 `control_ticks=1`，不能误当作四 tick 控制序列。

只有实际进入上述不变集才返回 proven。预算耗尽、时钟序列耗尽、先决条件缺失或受伤均返回 unknown。有限收敛段的安全检查与无限尾部的解析证明是两个独立义务。调用方负责把收敛段追加到可回放候选，不能只保存最终证书而丢弃动作。

Real HELL 最后一次重摔朝下、最大落速为 750、场地目标为 `[241,226,406,391]`、最后速度为 300，且原谱未开启 SlamDamage。该谱可能通过有限落地段进入证书集合，但 EOF 本身和环境 drained 都不自动证明玩家已处于不变集。
