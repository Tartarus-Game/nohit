# Exact fixed-red product operator

Implemented experimentally in `nohit/engine/factored_red.py`; production search is unchanged.

`solve_fixed_red(wave, start_tick, stop_tick, initial, controls=range(16), cspace=...)` returns all safe exit states (including each actual final input mask), a coupled reachable bitmap per layer, and one reconstructible witness per exit. `admissibility(...)` returns the first failed sufficient condition. Resource overflow raises `resource_limit`; it is never an unsolvability result.

The first implementation accepts only four-tick-aligned fixed-arena red slices, no active platforms/tombstones, no slam pulse or pending slam, no teleport, no target-observation boundary, and a starting point **strictly** inside the arena's heart interior. Each generated axis microtrajectory is also checked to remain strictly farther than13px from every border; any reachable contact rejects factorization. All clocks and coordinates retain exact float64 values. This is intentionally a small certified domain. Blue gravity, moving arenas and target-dependent environments remain outside it.

Inside that strictly verified domain, the horizontal contact test against the four finite border rectangles reduces to a condition on x, and vertical contact to a condition on y, since the other coordinate remains strictly inside the arena interior. Closed-set border contact is crucial: y=T+13 can block horizontal motion too, and x=L+13 can block vertical motion. Initial inclusive interior membership was insufficient and has been corrected; the new regression compares identical x/dx at y=T+13 and the next larger float, and observes different x successors. Factorization is rejected at the touching state. The mode is red and has no jump edge, so its velocity assignment is solely the selected mask. Thus within the verified strict domain the movement transition factors exactly:

F_t((x,dx),(y,dy),u) = (F^x_t(x,dx,u), F^y_t(y,dy,u)).

This is a product representation, **not** identification of unequal floating coordinates. The two axis automata retain every distinct bit pattern. A layer stores a Boolean relation R_t ⊆ X_t × Y_t as a bitset. Each actual legal mask advances both axes together and adds the resulting pair iff the original C-Space predicate is false at all four intermediate physical ticks. Geometry can couple x/y arbitrarily, including rotated lasers; the reachable set is not assumed rectangular. Cancel's75/150 speed choice is shared by both axes, so independent axis speed choices are never treated as a legal action.

The same relation supports forward Boolean reachability, or backward Bellman V_t(i,j)=OR_u(safe_t(i,j,u) AND V_{t+1}(fx,fy)). The current module implements forward reachability to expose the complete exit set. Interior old key masks can be omitted only because the next step is red. Final masks are preserved separately so an immediately following blue mode cannot lose a relevant jump latch. Paths reaching the same internal pair may share a witness; implicit original transitions retain the full safe-path language if enumeration is later requested.

Measurements:

- `scratch/probe_red_axis_product.py` uses actual Real HELL environmental ticks613–676 and recorded native dt, with an explicitly artificial center initial state. Before hazard filtering,16 control frames produce93 x states and93 y states, giving8,649 exact joint exits. All exits matched explicit2D enumeration. Axis records total186; joint reachability bitmap needs1,082 bytes versus761,112 bytes for8,649 bare11-float states, before hash-table overhead. This is a representation comparison, not a no-hit acceptance result or whole-solver speed claim.
- This slice had93 rounded-to-nine-decimal axis groups too: the experiment did **not** reveal extra float residue fragments. The opening's20,000-node search limit cannot be attributed to floating fragmentation from this measurement alone.
- `scratch/check_factored_red.py` compares the module to original full11-state step operator + C-Space exhaustive four-frame search.16-mask language:756 safe exact exits.32-mask language:4,540. Both complete exit sets match byte-for-byte; reconstructed witnesses also pass each physical tick.

Invalid shortcuts have small counterexamples in `scratch/probe_red_state_quotients.py`: x=321 and its immediately smaller float lie in the same4px cell and round identically, but a next-tick obstacle starting at323 collides with only one under the same coast input. Neither spatial-cell equality nor epsilon rounding preserves future safety language. By contrast, exact boundary clamp can make every same-mask successor identical, and a fixed teleport can collapse100 distinct precursor states to one output-labelled successor signature. Such event-induced equality is legitimate; proximity alone is not.

The smallest next integration is an opt-in fixed-red segment operator guarded by `admissibility`, with all exits passed to the existing general solver. A single best-looking exit must not replace that set. Performance work should batch the remaining exact joint collision predicates and retain the bitmap; it should not make collision geometry approximate or silently enlarge the legal action language.
