# 数学优化的验收合同

本轮遵循用户要求：先减少数学问题中的重复状态和重复转移，再改善实现。
Normal seed42 的整局无伤证据保留；Real HELL 尚未完成。

## 同一可达性问题

令完整状态为 $z_t=(s_t,e_t)$，包含角色状态、脚本位置、计时器、随机数状态、
目标采样及对话/输入边沿。确定时间步和控制字母表后，原规则给出
$z_{t+1}=F_t(z_t,u_t)$。安全谓词 $S_t$ 包含碰撞、重摔伤害和模式约束。
固定且不依赖角色的环境区间可以烘焙 $e_t$，此时节点只需保留 $s_t$。
GetHeartPos、对话输入等依赖不能被一个预选分支的环境替代。

分层可达性是

$$R_{t+1}=\{F_t(z,u):z\in R_t,\ u\in U_t,\ S_{t+1}(F_t(z,u))\}.$$

局部区间必须返回完整出口关系或明确的资源限制；一个入口耗尽不能推出其他
入口耗尽。四 tick 持键语言是逐 tick 语言的子集，前者耗尽不证明后者无解。

## 允许的状态合并

合并需证明：同类状态安全一致，且对每个控制，其后继仍等价。
本次 input-latch 商采用更强的充分条件：对所有合法 $u$，两个状态的下一步
完整结果逐位相同。下一步红心不读取旧按键；蓝心只读取下一重力方向的跳跃
边沿。内部层据此投影旧按键，保存真实代表及父链；最终层不投影，完整保留
包括末次按键的终点。这是未来安全控制语言等价，不是坐标近似。

轴分解是对 $F_t$ 的计算分解。即使适用区间中可分别计算横轴、纵轴，仍须
保留联合关系 $R_t\subseteq X_t\times Y_t$；一般不能令
$R_t=\operatorname{proj}_X R_t\times\operatorname{proj}_Y R_t$。
边界接触、平台和多步移动可使两轴耦合，未证明分解的边须调用完整算子。

## 奖励与正确性

奖励可以排序安全边，不改变上述集合定义。若还要求在所有安全路线中证明
某个加权总分最优，Bellman 值需要在同一终点更新最优父链。
仅证明动力学等价不足以合并奖励标签。例如旧 mask 为 0 和 RIGHT 的红心
状态，下一控制 RIGHT 的后继完全相同，但“是否切换按键”费用分别为 1 和 0。
此时应保留有关费用标签，或使用与奖励相容的更细等价关系。
当前局部关系用于布尔可达性，不据此声明任意权重的全局最优。

## 时间协议也是数学输入

原版有按 tick 累加的量，固定 240 Hz 和不规则 RAF 不是同一个转移序列。
本轮原版无 oracle/compensate 的 MainMenu 页面只读采样 2002.4 ms：
tickcount 增加 420，读取到 335 个不同 tick，观测 dt 的最小/中位/最大值
为 0.0039000000000232833 / 0.004199999999953434 / 0.0085 秒。
轮询遗漏部分 tick，这不是完整 dt 轨迹；页面菜单测量也不替代战斗测量。
它说明当前机器自然时钟存在约 4.2 ms 的步长及抖动，不能假定原版必定 60 Hz，
也不能把固定 240 Hz 的无伤证据扩大到任意卡顿。

## 已有量化结果

- 输入边沿商，500→612：全部 44,676 个终点逐位一致，4.491 s→1.722 s。
- 同商，固定旧入口 612→1528：两者均在 1512 耗尽，74.043 s→40.600 s。
- 根 agent 独立重跑局部关系/边沿商/closure 测试：21 passed in 1.60 s。
- 完整保留 tick500 来源的传播已保存到 tick636，共 955,400 个内部等价类；
  下一层超过 1,000,000 类预算，结果为 resource_limit，不能称为无解。
- 精确轴 ID 的联合边表示，616→620 保留全部 431,225 个完整终点：
  完整算子加去重 2.007 s，轴 ID 版本 0.769 s；临时边状态从 195.9 MB
  改为 17.8 MB 的整数键（父链、按键和其他数组另计）。尚未作为常驻前沿
  的完整替代，也未证明全段性能。

这些是局部加速证据。不能外推为 Real HELL 已解、全部原版输入完备，或全流程
毫秒级。下一验收目标是从更早入口保留完整关系穿过失败区域，并重放数学见证。
